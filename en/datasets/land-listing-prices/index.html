Questions this data can help answer

  • How do asking prices and plot sizes differ among land listings?
  • How can asking and appraisal values help shortlist listings for follow-up?

How to start reading the data

Read total asking price, price per square wa and plot size together before comparing with appraisal values. A price gap is a starting point for investigation, not an achievable closing price. Check listing dates, sources, duplicates and outliers before comparing records.

Know before use

Listing prices are not closing prices; duplicate and outlier handling is not yet documented
