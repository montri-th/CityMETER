How to start reading the data

The gap between asking and appraisal values can guide further project research. Before drawing conclusions, check how units and projects were matched, whether units of measurement agree, and how duplicates were handled. Asking prices remain distinct from completed transaction prices.

Know before use

Asking prices are not closing prices; duplicate and outlier handling is not documented
