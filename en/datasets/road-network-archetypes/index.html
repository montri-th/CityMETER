Road Network Archetypes

Read street-network patterns as neighbourhood characteristics before planning a location study.

Open the map ↗

Street networks connect places in different ways

In the Bangkok example, dead-end shares and junction density add context beyond road lines. Use the pattern to frame questions about real routes into the area.

Network form is not traffic, journey time or a score that determines whether a location is good or bad.

Two questions to start with

  • How connected or dead-end-heavy is the network?
  • Which access routes should you try in person?
