Questions this data can help answer

  • What kinds of projects and assessment records are found around this location?
  • Which original project reports would help clarify the development context?

How to start reading the data

Read project locations with their IEE, EIA or EHIA assessment type, then consult the original reports. The map is a curated, geocoded snapshot. A report or approval does not establish construction, operation or compliance, so use it for initial development context rather than a determination of development rights.

Know before use

Use for initial context, not as a determination of development rights or approval status
