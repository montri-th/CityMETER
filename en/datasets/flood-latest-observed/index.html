Review satellite-observed flood areas for a selected date and study their watershed context.

Questions this data can help answer

  • Where was flooding detected on the selected observation date?
  • How can watershed context and spatial overlays help review that event?

How to start reading the data

Start with the observation date, then read flood extent alongside watershed context and spatial overlays. “Latest” refers to the available dated observation, not live conditions. An uncoloured area does not establish that the location is safe.

Know before use

The latest observed layer is a dated snapshot, not present conditions
