Questions this data can help answer

  • How do appraisal values per square metre differ between condominium projects?
  • Which neighbourhood appraisal ranges merit comparison with market evidence?

How to start reading the data

Use building or project appraisal values as an official baseline for comparing neighbourhoods. Compare that baseline separately with checked listing or transaction evidence. A project appraisal does not establish the current asking or closing price of a particular unit.

Know before use

Appraisal values are neither listing prices nor transaction prices
