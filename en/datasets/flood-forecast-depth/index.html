Questions this data can help answer

  • What flood depth does the model forecast for the selected area and period?
  • How do the model run time and limitations affect interpretation of the forecast?

How to start reading the data

Read modelled depth with the forecast period, run time and method. Check coverage and resolution before applying a province-level comparison to a smaller location. A forecast is not an observed water level, confirmation that an event will occur or emergency guidance.

Know before use

Model output is not confirmation of an event; show run time, source, method, and limitations
