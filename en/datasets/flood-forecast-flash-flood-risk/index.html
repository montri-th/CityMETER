How to start reading the data

Use the forecast as a monitoring signal alongside situation checks and relevant notices. Read the run time, validity window and experimental status each time. It does not confirm that an event will occur, and model resolution needs checking before applying it to a specific location.

Know before use

This is a model signal, not confirmation that an event will occur; retain the experimental status
