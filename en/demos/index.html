CityMETER demos

15 datasets as prototypes on GitHub Pages, using the same area codes as CityMETER on landometer.com. Pick an area here once, and every demo link below opens that area.

  • The demos are prototypes for trials and further development, not the production CityMETER.
  • Read each demo's sources, period and limitations before using its numbers.
  • The demos are in Thai for now; Hotel, Industrial Estate, Office, Factory, Hospital, Pharmacy, Restaurants, School and Government Office also read in English (a draft translation), and their links here open them in English. The English lines on this page are drafts.

For developers

  • Every demo runs the same bytes of the shared code citymeter-shell 0.5.4; the list and groups on this page match the dataset picker in the demos' header (js/shell/datasets.js).
  • Demo address: d (dataset code) · at (area, e.g. BKK/D/1039, which is /v3/citymeter/BKK/D/1039 in production) · e (the thing open) · n (a network) · f.* (filters) · focus · view · v3d · cam.
  • Land · Location · Living follow the dataset registry (R01_DATASETS, read 2026-11-08), as this catalog's lenses do for every demo with a catalog page.
  • Each question is quoted from the demo page's meta description (Thai); the English line under it is a draft.
  • Search engines do not index the demos or this page (noindex).
