โครงการและรายงาน EIA

รู้จักโครงการรอบทำเลผ่านข้อมูลและรายงาน EIA ก่อนเปิดเอกสารฉบับเต็มของโครงการที่เกี่ยวข้อง

เปิดข้อมูลบนแผนที่ ↗

จากตำแหน่งโครงการไปสู่เอกสารที่ควรอ่าน

แผนที่ช่วยเชื่อมชื่อโครงการกับพื้นที่จริง เห็นประเภทและประวัติที่เกี่ยวข้องกับทำเล แล้วเลือกอ่านรายงาน IEE, EIA หรือ EHIA ของรายการที่สำคัญกับโจทย์ของคุณ

ข้อมูลบนแผนที่เป็นรายการที่นำเข้ามา ไม่ยืนยันสถานะอนุมัติปัจจุบัน การก่อสร้าง หรือการปฏิบัติตามมาตรการ

ลองเริ่มจากสองคำถามนี้

  • รอบทำเลนี้มีโครงการประเภทใดอยู่ในข้อมูล?
  • รายงานฉบับไหนควรอ่านก่อนพิจารณาพื้นที่ต่อ?

ดูพื้นที่ที่คุณสนใจต่อ

ผู้เผยแพร่ข้อมูล
สผ. / ONEP
ที่มา
ชื่อโครงการ เจ้าของ ประเภทรายงาน เอกสาร วันที่อนุมัติ ประเภทโครงการ และพื้นที่ตั้งตรงกับ Smart EIA
ช่วงเวลาของข้อมูล
ปีของโครงการและช่วงข้อมูลขึ้นอยู่กับรายการที่นำเข้า ให้ตรวจวันที่รายงานและสถานะของโครงการที่สนใจ
พื้นที่ครอบคลุม
มีหน้าสรุประดับประเทศไทย แต่ขอบเขตข้อมูลต้นทางยังไม่ระบุ
ระดับรายละเอียด
โครงการและประเภทการประเมิน IEE, EIA หรือ EHIA ตามรายการที่มี

อ่านแหล่งอ้างอิง

  • ONEP Data Catalog (เปิดแท็บใหม่)
  • Smart EIA Open API (เปิดแท็บใหม่)
  • GD Catalog (เปิดแท็บใหม่)
